Privacy policy

This application is used only by its owner to back up the owner's own photos to the owner's own Google Drive.

  • It requests only the drive.file scope, so it can access only files it has created itself.
  • It does not collect, store, sell, or share any personal data with any third party.
  • Authorisation tokens are stored only on the owner's own computer.
  • No analytics, advertising, or tracking is used.

Contact: via the repository owner's GitHub profile.
